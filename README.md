# Festiv

Festiv es un sitio web de experiencias para eventos sociales que ofrece cabinas de fotografía y video, así como montajes personalizados, con el objetivo de convertir cada celebración en un recuerdo especial.

## Sitio web

[Ver sitio web](https://andrik87.github.io/proyecto-festiv/)

## Tecnologías utilizadas

- HTML5 semántico.
- CSS3.
- Sass (SCSS), organizado en partials con variables, mixins y extends.
- Bootstrap.
- Animate.css.
- Git y GitHub.

## Características

- Diseño responsive con enfoque Mobile First y uso de media queries.
- Navbar responsive con menú hamburguesa.
- Carrusel de experiencias con Bootstrap.
- Tarjetas organizadas con el sistema de grillas de Bootstrap.
- Estilos personalizados con la identidad visual de Festiv.
